Random Forest Gini / MDI Feature Importance

Identifies which input features have the strongest statistical weight on house valuation.

Key Feature Takeaways

  • 1
    Built-up Area (sq.ft) (~62.5%):

    The single most dominant price predictor. Price scales proportionally with carpet and super built-up area.

  • 2
    Location Factor (~28% combined):

    High-end tech hubs like Koramangala, Indiranagar, and Jayanagar command 2x to 3x higher base rate per sq.ft compared to outer corridors.

  • 3
    Property Age & Bathrooms (~5%):

    Newer properties have lower depreciation. Additional bathrooms add luxury premium.

Algorithm 1

Linear Regression

A supervised learning algorithm that models the linear relationship between independent variables and continuous price target.

y = β₀ + β₁(sqft) + β₂(bhk) + β₃(baths) + ∑ βᵢ(loc_i) + ε
Key Assumptions:
  • Linearity between features and target
  • No severe multicollinearity (checked with VIF)
  • Homoscedasticity (constant variance of residuals)
Strengths: Highly interpretable, extremely fast training, great mathematical baseline.
Algorithm 2

Random Forest Regressor

An ensemble learning method that fits 150 randomized decision trees (bagging) and outputs the mean prediction.

ŷ = (1 / B) ∑ₖ₌₁ᴮ Tₖ(x)
Why it out-performed Linear Regression:
  • Captures non-linear interactions (e.g. large luxury penthouses have exponential price scaling)
  • Robust against outliers due to tree voting aggregation
  • Does not require feature scaling to be effective
Hyperparameters used: n_estimators=150, max_depth=12, random_state=42.
